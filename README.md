# Halloween Night — Multilingual Edition

เว็บ Halloween แบบ static เขียนใหม่จากคอนเซปต์ในไฟล์ต้นฉบับ รองรับ **12 ภาษา** โดยไม่ต้องติดตั้ง framework หรือ backend

## ภาษา

ไทย (`th`), อังกฤษ (`en`), สเปน (`es`), ฝรั่งเศส (`fr`), เยอรมัน (`de`), โปรตุเกส (`pt`), ญี่ปุ่น (`ja`), เกาหลี (`ko`), จีนตัวย่อ (`zh`), เวียดนาม (`vi`), อินโดนีเซีย (`id`), อาหรับ (`ar`, รองรับ RTL)

- ตรวจจับภาษาผู้เข้าชมอัตโนมัติจาก `navigator.languages` (ภาษาที่ผู้ใช้เรียงไว้ในเบราว์เซอร์), `navigator.language` และ locale ของ `Intl` (สำรอง) โดยไม่ใช้ IP / ตำแหน่ง / API
- ถ้าเบราว์เซอร์ส่ง locale เช่น `th-TH` หรือ `ja-JP` จะจับคู่เป็น `th` หรือ `ja`; ถ้าไม่รองรับทุกตัวเลือกจะใช้ภาษาอังกฤษ
- ถ้าผู้ใช้เปลี่ยนค่าภาษาในเบราว์เซอร์ระหว่างเปิดหน้าเว็บ และเบราว์เซอร์ส่ง `languagechange` เว็บจะอัปเดตโดยยังเคารพภาษาที่เลือกเองหรือจาก URL
- เลือกภาษาเองจาก dropdown และจดจำค่าใน `localStorage`
- เปลี่ยนภาษาด้วย URL เช่น `?lang=th`, `?lang=ja`, `?lang=ar` (URL มาก่อนค่าที่บันทึกไว้)
- เปลี่ยนทั้งข้อความ ป้ายควบคุม หัวข้อหน้าและ meta description

## รันเว็บ

เปิด `index.html` ในเบราว์เซอร์ได้โดยตรง หรือใช้ local server เพื่อจำลองการโฮสต์จริง:

```bash
cd halloween-multilingual
python3 -m http.server 8080
```

แล้วเปิด `http://localhost:8080/?lang=th`

## โครงสร้าง

```text
halloween-multilingual/
├── index.html           # โครงหน้าเว็บและปุ่ม
├── styles.css           # หน้าตา / responsive / reduced motion / RTL
├── i18n.js              # คำแปลทั้ง 12 ภาษา
├── app.js               # ระบบภาษา + เล่นวิดีโอ
└── assets/
    └── scare.mp4        # วิดีโอที่แยกออกมาจากไฟล์ HTML เดิม
```

## เปลี่ยนคำแปลหรือเพิ่มภาษา

1. เพิ่มภาษาใหม่ใน `i18n.js` โดยใช้ key ให้ครบตาม `en`
2. เพิ่ม `<option value="xx">ชื่อภาษา</option>` ใน `index.html`
3. หากภาษานั้นอ่านจากขวาไปซ้าย ให้แก้เงื่อนไข `dir` ใน `app.js`

## พฤติกรรมที่คงไว้จากต้นฉบับ

**ทั้งปุ่มตอบตกลงและปุ่มปฏิเสธจะเล่นวิดีโอเซอร์ไพรส์เหมือนกัน** ตามโค้ดต้นฉบับ ปรับเปลี่ยนได้ใน `app.js` ที่ event listeners ของ `accept-button` และ `decline-button`

ปุ่มกลับ, เล่นซ้ำ, ปิด/เปิดเสียง และปุ่ม Escape เพิ่มใหม่เพื่อให้ผู้เข้าชมควบคุมได้เอง

ระบบไม่ใช้ API หรือ CDN ภายนอก เหมาะกับ GitHub Pages, Cloudflare Pages หรือ static hosting ทั่วไป
